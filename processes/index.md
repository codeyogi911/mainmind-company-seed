# Process index

Route work here first. Describe the task the way you would say it out loud,
and take the process that matches.

`unmatched:` above names what to do when nothing here fits, so the rule lives
in one place instead of being scattered through prose an agent has to spot.

- **daily-review.md** — the morning pass: read yesterday, reconcile the money,
  handle what is already settled, hold everything else.
- **nothing-fits.md** — no process covers this task: name the gap, do the
  smallest honest version inside existing permission, leave a draft behind.

*Add a row for every process you write. One line, in the words someone would
use to ask for it — that phrasing is what routes work to the right place.*
