# Nothing fits — name the gap

## What it is for

A task arrived that no process covers. This is what to do about it.

## When to use it

When you have looked and genuinely found nothing — not when the nearest
process is merely awkward. Bending a process to cover work it was not written
for is worse than having no process, because the next agent inherits the bent
version as if it were deliberate.

## What this process lets an operator do

Nothing beyond [AUTHORITY.md](../AUTHORITY.md). The task still runs under whatever permission
already existed — this process changes what you *write down*, never what you
are allowed to *do*.

That matters most here, precisely because it is tempting: an unmatched task
feels like an exception, and exceptions are where unauthorised acts get
rationalised.

## Steps

1. **Say plainly that nothing matched**, and say what you searched for. The
   absence is a finding worth reporting on its own.
2. **Check that it is really absent.** List the processes rather than trusting
   a search that came back empty — searching and not finding is not the same
   as there being none.
3. **Do the smallest honest version of the task**, inside permission you
   already have. If any part of it is reserved in `AUTHORITY.md`, stop there
   and ask instead.
4. **Leave the draft behind.** Write the process you wished you had found into
   `proposals/`, not `processes/` — `processes/` is reserved, so putting it
   there directly would be performing a reserved act while trying to be
   helpful. If it was genuinely a one-off, write that down instead; it is what
   stops the next agent working it out from scratch.

## How you know it is done

The task is handled or explicitly parked, and the repository now contains
either a proposed process or a note saying why it does not need one. If
neither exists, the work happened and taught the company nothing.

## A note on repeats

The same gap drafted twice is a routing problem, not two missing processes.
Fix how `processes/index.md` describes the existing one instead of adding a
third.
